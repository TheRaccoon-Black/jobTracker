Product Requirements Document (PRD): JobTracker Pro1. Ringkasan Eksekutif (Executive Summary)Tujuan Produk:Membangun platform Job Application Tracker berbasis web yang esensial untuk memfasilitasi pencari kerja dalam mengelola, melacak, dan menganalisis seluruh siklus lamaran kerja mereka dari satu dasbor terpusat.Latar Belakang:Proses pencarian kerja modern melibatkan pengiriman puluhan lamaran lintas platform dengan berbagai tahapan wawancara. Tanpa sistem pencatatan yang terstruktur, kandidat sering kehilangan konteks terkait tautan lowongan asli, rentang gaji yang disepakati awal, atau nama pewawancara. Platform ini dirancang untuk menyelesaikan fragmentasi data tersebut dengan menyediakan manajemen status yang sistematis.2. Spesifikasi Teknologi (Tech Stack)Backend: Laravel (versi 11.x) menyediakan arsitektur MVC yang solid untuk manajemen routing dan logika bisnis.Database: MySQL (versi 8.x) untuk relasi data yang kompleks dan terstruktur.Frontend: Ekosistem Laravel (Blade Templates) dikombinasikan dengan Tailwind CSS untuk antarmuka yang responsif dan modern. Svelte dapat diintegrasikan via Inertia.js jika interaktivitas komponen tingkat lanjut diperlukan.Autentikasi: Laravel Breeze atau Jetstream.Infrastruktur & Deployment: Lingkungan server Linux (Ubuntu) menggunakan web server Nginx/Apache, dikelola melalui pipeline Git dasar.3. Kebutuhan Fungsional (Functional Requirements)3.1. Autentikasi & Manajemen PenggunaRegistrasi akun baru menggunakan kredensial email dan password.Manajemen sesi yang aman (Login, Logout, dan Password Reset).Manajemen profil pengguna dasar.3.2. Manajemen Lamaran (Core Application Tracker)Pengguna dapat membuat, membaca, memperbarui, dan menghapus (CRUD) entri lamaran dengan formulir komprehensif yang mencakup atribut berikut:Company: Nama entitas perusahaan yang dituju.Title: Nama posisi atau peran yang dilamar.Status: Indikator pergerakan proses rekrutmen (Wishlist, Applied, Assessment, HR Interview, User Interview, Offered, Rejected, Ghosted).Job Posting Link: URL referensi dari portal lowongan (sebagai cadangan jika iklan diturunkan).Contact: Informasi Person in Charge (Nama rekruter, email, atau nomor telepon untuk follow-up).Application Date: Tanggal presisi saat lamaran disubmit.salaryRange: Rentang kompensasi (ekspektasi kandidat atau budget yang dicantumkan perusahaan).Notes: Ruang teks bebas untuk mencatat konteks spesifik (misal: "Kirim via portal internal, butuh referensi internal").3.3. Manajemen Tahapan & Wawancara (Interview & Assessment)Sub-modul terintegrasi di dalam setiap entri lamaran untuk mencatat pergerakan tahapan seleksi:Interview Stage: Kategori spesifik dari tahapan terkini (Screening, HR Interview, Technical Test, User Interview, Final/C-Level Interview).Interviewer: Nama lengkap dan jabatan evaluator/pewawancara.Schedule Details: Tanggal, waktu, dan tautan pertemuan virtual (Zoom/Google Meet) atau lokasi fisik gedung.3.4. Manajemen Dokumen (Document Vault)Sistem repositori terpusat bagi pengguna untuk mengunggah berbagai iterasi CV, portofolio, dan Cover Letter.Kemampuan menautkan spesifik ID dokumen ke spesifik ID lamaran untuk melacak versi CV mana yang dikirim ke perusahaan tertentu.3.5. Dasbor & Analitik KinerjaVisualisasi agregat berupa total lamaran yang dikirim.Kalkulasi Conversion Rate (Persentase lamaran yang tembus ke tahap wawancara).Distribusi visual status lamaran aktif menggunakan Pie Chart atau Bar Chart.4. Kebutuhan Non-Fungsional (Non-Functional Requirements)Keamanan Data: Implementasi perlindungan CSRF bawaan Laravel pada semua form. Kata sandi dienkripsi menggunakan Bcrypt. Mencegah kerentanan SQL Injection melalui penggunaan ketat Eloquent ORM.Optimalisasi Kinerja: Waktu muat halaman ditargetkan di bawah 2 detik. Penggunaan Eager Loading (with()) pada Eloquent untuk mereduksi problem N+1 Query saat memuat daftar lamaran beserta jadwal wawancaranya.Responsivitas: User Interface harus mengadopsi prinsip mobile-first design menggunakan utilitas Tailwind CSS untuk memastikan kelancaran akses melalui perangkat seluler.5. Fase Pengembangan (Milestones)Fase 1: Konfigurasi Dasar & Arsitektur Instalasi kerangka kerja Laravel dan pengaturan koneksi MySQL.Implementasi autentikasi pengguna.Pembuatan eksekusi Migrations, Models, dan relasi Eloquent (User, Application, Interview, Document).Fase 2: Fungsionalitas Inti CRUD Membangun rute (Routes) dan Pengendali (Controllers) untuk entitas Applications dan Interviews.Pembuatan antarmuka formulir input menggunakan Blade dan Tailwind CSS yang mengakomodasi seluruh parameter data baru (Contact, salaryRange, Interviewer).Validasi form (Form Requests) di sisi backend.Fase 3: Repositori Dokumen & Tampilan Visual Pengembangan logika pengunggahan file ke direktori lokal storage Laravel.Penyempurnaan tata letak Dasbor utama untuk menampilkan agregasi metrik pencarian kerja.Fase 4: Quality Assurance & Deployment Pengujian menyeluruh guna memastikan data tidak dapat diakses oleh user_id yang salah (Authorization Policies).Persiapan server Linux, konfigurasi virtual host web server, dan deployment basis kode ke lingkungan produksi.
